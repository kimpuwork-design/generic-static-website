# SMM Panel (cPanel-ready)

A powerful, cPanel-friendly Social Media Marketing (SMM) panel built with PHP and MySQL. Features include:
- Multi-provider support (SMM API v2) with service syncing
- Wallet system with transactions
- PayPal IPN deposits (optional)
- Order placement and status updates
- Client API for placing orders and checking status
- Admin area for provider management and service syncing
- Simple, clean UI

## Requirements

- cPanel hosting with PHP 7.4+ and MySQL
- cURL enabled
- Cron jobs (optional but recommended for auto status updates)

## Installation

1. Upload the files to your `public_html` (or document root) on cPanel.
2. Create a MySQL database and user via cPanel.
3. Visit `/install/install.php` in your browser.
4. Fill in the database credentials, admin details, and optionally enable PayPal IPN.
5. Installer will create `config.php` and initialize the schema.
6. Delete the `install/` folder for security after installation.

## PayPal IPN

If enabled during setup:
- Add your PayPal business email and currency.
- IPN endpoint: `https://yourdomain.com/ipn/paypal.php`
- Ensure IPN is enabled in your PayPal account settings.
- Deposits credit automatically when PayPal sends IPN.

## Cron job (recommended)

Set a cron job in cPanel to update orders periodically, e.g. every 10 minutes:

```
php -d detect_unicode=0 /home/USERNAME/public_html/tasks/cron_update_orders.php
```

Replace `USERNAME` and path as needed.

## Providers

Add providers in Admin → Providers:
- Name: your reference label
- Base URL: provider API v2 endpoint (e.g., `https://provider.com/api/v2`)
- API Key: provider API key
- Markup: percentage applied to base rate per 1000

Use "Sync Services" to fetch the latest catalog and rates.

## Client API

Base: `index.php?route=api`

- `POST ...&action=balance`: returns wallet balance and currency
- `POST ...&action=services`: returns current services
- `POST ...&action=add` with `service`, `link`, `quantity`: places order
- `POST ...&action=status` with `order`: returns order status and charge

Authenticate via `key` in POST body (your API key is shown on Dashboard).
