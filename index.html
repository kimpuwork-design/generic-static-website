SMM Panel Preview

This is a static preview of the panel UI. The full app runs on PHP/MySQL via index.php on cPanel.

Features:

  • Multi-provider support with SMM API v2
  • Wallet, deposits (PayPal IPN), transactions
  • Order placement and automatic status updates via cron
  • Client API for balance, services, add order, status
  • Admin provider management and service synchronization

To use the full panel: upload to cPanel and visit /install/install.php.

API Documentation

Base: index.php?route=api

  • Balance: POST ?route=api&action=balance → { balance, currency }
  • Services: POST ?route=api&action=services → list
  • Add: POST ?route=api&action=add with service, link, quantity → { order }
  • Status: POST ?route=api&action=status with order → { status, charge }
curl -X POST "https://yourdomain.com/index.php?route=api&action=services" -d "key=YOUR_API_KEY"
